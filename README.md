# Operasi Sentinel · Two Rooms and a Boom

Aplikasi kartu peran rahasia untuk simulasi *Two Rooms and a Boom* pada Program Penjenjangan Karier Manajer Pratama BPJS.

- Buka: https://awelogi.github.io/operasi-sentinel/
- Setiap peserta membuka aplikasi di HP masing-masing, memasukkan **kode operasi** dari fasilitator dan **nomor agen**, lalu menerima perannya.
- Tidak butuh server. Setelah dibuka sekali, aplikasi tersimpan di HP dan bisa dipakai tanpa internet.

## Isi

| File | Fungsi |
| --- | --- |
| `index.html` | Seluruh aplikasi (tampilan, logika peran, font tertanam) |
| `sw.js` | Menyimpan aplikasi agar bisa dibuka offline |
| `manifest.json`, `icon-*.png` | Supaya bisa dipasang di layar utama HP |
